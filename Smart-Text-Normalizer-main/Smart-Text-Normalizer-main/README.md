# Smart Text Normalizer

## Project Overview
Smart Text Normalizer is an NLP-based application that converts informal text,
slang, and abbreviations into standard English.

## Technologies Used
- Python
- Streamlit
- NLTK

## Features
- Slang and abbreviation normalization
- NLP tokenization
- Normalized text output
- Changes made display
- Text statistics
- Normalization percentage

## Example

Input:
Thx for ur help

Output:
Thanks for your help
